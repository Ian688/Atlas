# W09：167 处未知变成可点清单（以及它说出的那件事）

窗口：`2026-09-12/w09-unknown-list`
结论：**DELIVERED**。一个数字变成清单之后，**清单说出了数字说不出的话**。

## 1. 交付

首屏「显式未知」卡片下新增「查看这 167 处未知 →」，展开**显式未知清单**：
按原因分组、每一处带**文件 + 字节区间**、点一条即按身份打开该文件（走 `/api/node`，不靠翻页），
状态栏报出该区域的字节区间；显示有上限时明写「其余 N 处同因（按显示上限省略，不是不存在）」。
深链接支持 `&panel=unknowns`（无头浏览器点不了按钮，这也是唯一能截图验证的方式）。

## 2. 清单说出的那件事（本轮真正的产出）

167 处未知**不是一片模糊的前沿，是三个不支持的语言特性**：

| 原因 | 处数 | 位置特征 |
|---|---|---|
| `for_in_of_iteration` | **79** | 全部在 `dist/bundles/*.js`（打包产物） |
| `rest_parameter` | **78** | `dist/esm/**` 与 `src/**`（`bindCallbackInternals`、`combineLatest`、`concat`、`forkJoin`、`fromEvent`、`merge`、`of`…） |
| `destructuring_parameter` | **10** | `operators/windowTime.ts`、`testing/TestScheduler.ts` 等 |

**157/167 = 94% 来自这三件事**；只补 rest 参数与解构参数两项，就能消掉 **88 处（53%）**。

这是"呈现承担表达"的实例：覆盖率数字（167）本身不可行动——不知道在哪、什么原因、先修哪个；
分组之后它直接给出了**下一步该做什么**，而且这个结论是从事实里长出来的，不是猜的。

## 3. 过程中的一个错误（看图才发现）

清单第一版用了画布容器的定位类（`position:absolute;inset:0`），结果**把整页盖住了**：
截图里只剩下清单，页眉、卡片、工作台全部不见。改成文档流内的独立类后恢复正常。
——又一次证明：不看画面，我不知道自己做出来的是什么。
