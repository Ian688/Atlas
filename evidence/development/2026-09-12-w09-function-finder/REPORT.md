## 1. 交付

**第一屏：这个项目最该先知道的五件事。** 打开 Atlas 不再先看到层级网格，而是五行全量事实：
规模（文件 1,255 · 函数 6,573 · 调用点 14,476）、解析覆盖（清单 2,365 项含目录 88 / 已解析 1,255）、
函数级完整度（6,573 有局部事实 · 部分完成 0 · 前沿 0）、**显式未知 167 处**、跨过程结构（SCC 6,568 · 递归 19）。
全部取自 `/api/report` 的全量字段，**不从「本页已加载的一页」推算**——那正是之前把 2080 印成项目函数总数的原因。
底部常驻一行：`上面是全量事实。本页只加载了 100/8938 个对象——画布与清单只画已加载的部分，且会自己说明这一点。`

**找函数。** `/api/nodes` 一页 100 条、按 id 排序，目录与文件在前，**第一页里一个函数都没有**，
因此页面此前**没有任何路径能选中一个函数**，而函数是进入其余全部能力的入口。
实现：有界翻页（每页 500，上限 24 页）只留 `kind === 'function'`；状态显示「全部 N 个函数」或
「前 24 页 · N 个（未穷尽）」；搜索按函数名 + 路径过滤，命中上限 200 并写明「匹配 N 个，显示前 200 个」；
点命中即 `select(node)`。
