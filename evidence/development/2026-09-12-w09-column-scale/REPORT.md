## 1. 问题：等比高度说的不是分析说过的话

文件柱的高度以前是 `BASE + N × SLAB_H`——**按声明函数数量等比**。听起来中性，实际上在真实项目上它输出一个错误结论。

实测 rxjs@7.8.1 的 2277 个文件对象：

| | 最高柱 = 1.0 | 中位柱 | 不足最高柱 1% 的列 |
|---|---|---|---|
| 等比高度（修前） | 1.0 | **0.003** | **850 / 923 = 92.1%** |
| 分段尺度（修后） | 1.0 | **0.103** | **0 / 923 = 0%** |

也就是说：修之前，**在屏幕上根本看不见 92% 的"有函数的文件"**，同时一个 1056 函数的 bundle 把整张图压成地平线。读者看到的是"那个文件就是整个项目"——**分析从来没这么说过**。这不是审美问题，是错误陈述。

## 2. 交付：`web/hierarchy.js` 里的尺度合同（两个投影共用）

规格 design §13.2 早就把尺度写死了，我照它实现，并且**两个投影读同一份实现**（第二个尺度函数会和第二个层级一样悄悄漂移）：

- `atlasScaleHeight(n)`：N=0 → 矮柱 `0.45` 层（显示文件角色）；1–8 → 线性（每层可辨）；>8 → `8 + 3·log2(n/8)`，封顶 `80` 层。
- `atlasScaleTier(n)`：`flat / linear / thin / group / compressed`，对应规格的 N=0 / 1–8 / 9–20 / 21–50 / >50。
- `atlasScaleRadius(n)`：**按构造饱和**（`1 + 0.35·min(1, log1p(n)/log1p(1024))`），所以半径永远不可能变成读者真正比较的那个通道。第一次写的时候它没有饱和，被自己的基准检查抓出来了（见 §4）。
- `atlasScaleCompression(n)`：给出档位、压缩高度、线性高度、压缩起始层，供渲染器**标注**而不是让人去量。
- `atlasScaleReport(counts)` / `atlasScaleRuler(counts)`：可读性报告与标尺刻度。
- 2D 的状态行也读同一个函数并报出同一组数字（"柱高尺度（与 3D 同一函数）中位/最高 … · 不足最高 1% 的列 …（线性尺度下 …）"），所以"共用一个尺度"是可检查的，不是源码里的一句话。

**渲染层的三处改动**（`web/city3d.js`）：

1. 柱高走共享尺度（这是把谎言修掉的那一处）；
2. 压缩柱上画一条**压缩标记环**（`CITY_PALETTE.compression`）——没被标出的压缩高度就是一个更好看的错误数字；
3. 层数受**压缩后的高度**限制（`min(loaded, 18, floor(scaleHeight))`），并且"未展开的剩余层"填满柱子的实际剩余空间——否则层片会叠到自己柱子顶上去。

## 3. 可读性变成数字：`scripts/bench_view_readability.py`

判据是三条可被读者检查的陈述，而不是形容词：

- 任何**带有函数的柱**不得画到最高柱的 1% 以下；
- 中位柱必须高于最高柱的一个下限（真实项目 0.05，合成 fixture 0.25——真实包确实由小文件主导，把下限压得更低是削弱检查而不是描述事实）；
- 压缩必须真的压缩、必须被标出，尺度必须单调、且恰好在前 8 层线性。

**这条检查必须能失败**，否则它是装饰：脚本同时断言**被替换掉的等比尺度在同一条判据上失败**（`linear.onePct > 0`）。真实数据上它是 850，所以判据是活的。

尺度公式**只有一份实现**：脚本不重抄公式，而是通过 `scripts/scale_report.mjs` 在 `node:vm` 里加载 `web/hierarchy.js` 取值。在 Python 里再写一遍就等于制造我刚花一轮消灭的那类漂移。

已进入门禁：`view-readability` 每次运行都跑（`--self-check`，无 store、无网络）。

## 6. 没有做的事

- **这一轮只修了尺度这一条**。规格 §13 的其余缺口一条都没动：没有玻璃（`alpha:false` + `vec4(...,1.0)`）、没有**边界端口**（跨目录调用仍是块心直连）、没有正交/平面 2.5D 视角、没有相机与折叠的跨视图保存、页面仍常驻 `requestAnimationFrame`、没有搜索定位到层、没有类层组标题、没有 `visibility_reason`、没有文件树/全局小图/时间轴。
- **2D 完全没有变好**：它仍没有分层布局、没有端口、没有摘要边语义；这一轮它只是**读取了同一个尺度函数**并在状态行报出同一组数字。2D 的真实布局是下一步（下一轮）。
