# Atlas 当前执行任务书

版本 **6.0 · 项目地图与多展示区**。用户要求开发 Agent 按最新探索页设计实现产品。当前顺序为 **M1 → M6**，不是重新执行旧 v5 的六页改版。

唯一详细实施说明：[开发 Agent 提示词](design/atlas-explore-next/DEVELOPMENT_PROMPT.md)。从这里读当前节点操作、页面行为、数据/版本归属、模型与 Agent 接入边界、真实验收路线。

先实际打开[最新原型](design/atlas-explore-next/index.html)，看[功能设计](design/atlas-explore-next/DESIGN.md)和[多区域截图](design/atlas-explore-next/images/02-multiple-areas.png)。原型仅为设计，生产数据、生成、运行和写入必须接真实能力。

| 顺序 | 交付 |
|---|---|
| M1 项目地图 | 当前项目根节点、递归目录/文件/成员、搜索与按需加载、内容与节点入口 |
| M2 多区域工作区 | 独立标签/区域、地图/内容/关系、布局与管理、按项目保存恢复 |
| M3 节点知识 | 真实算法简介与注释、可编辑解析及历史、批注与关注 |
| M4 节点任务 | 按类型操作、运行/Review、交接与提案关联、3D同对象往返 |
| M5 按需 LLM | 显式配置和生成、范围预览、取消/失败、解释与用户记录分离 |
| M6 最终交付 | 新分发包、仓库外双项目旅程、实际画面、报告及当前指针 |

已有运行、取消、验证、应用/撤销、项目设置和 R1–R4 整改继续复用，不重新实现。旧 U5/U6 尚需核对的 Agent 与 3D 路径纳入 M4/M6，不作为另一条并行任务清单。

后端按具体页面操作补能力。常规组件拆分、库选择、存储调整自行决定；保留共享工作树。缺少真实模型配置时完成连接/状态及其他独立步骤，真实外部调用单独记为待验证；不能用演示回复算完成。

验收按提示词中的真实操作路线执行：尤其是多区互不覆盖、同名双项目隔离、真实提案与写入字节、重启恢复。运行适用检查、核对最终包身份；一份新报告和 progress 指针即可。自测与独立复审分开记录。

语言中立、开发者与 Agent 共用依据、2D/3D方向不变。继续保持固定版本、明确未知、有界可取消工作、本地数据与用户授权写入。

旧 [v5 任务书](../evidence/documentation/explore-map-order-v6/DAILY_DEVELOPMENT_WORK_ORDER.md)已存档，不影响已完成阶段的验收记录。
