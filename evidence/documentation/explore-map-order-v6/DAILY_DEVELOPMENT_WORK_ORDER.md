# Atlas 当前执行任务书

版本 **5.0 · 完整界面交付**。用户最新决定：当前主线是 UI、交互和页面可见的能力；后端为这些用户操作提供支持。旧 S1–S6 的实现继续复用，旧复审 R1–R4 随对应页面修正，不再作为单独优先队列。

**唯一当前执行顺序：U1 → U6。**

先打开 [完整可点击原型](design/atlas-v2/index.html)，看 [六页设计图](design/atlas-v2/gallery.html)。再按 [实现 Agent 提示词](design/atlas-v2/DEVELOPMENT_PROMPT.md) 开发；完整设计、逐按钮交互和技术栈落点从 [设计包](design/atlas-v2/README.md) 查当前页面即可。

| 顺序 | 交付给用户的变化 | 完成线 |
|---|---|---|
| U1 共用空间与探索 | 清楚的导航、搜索、关系、源码、值与未知 | 找到真实函数→点关系→定位源码→带同对象进入运行 |
| U2 运行验证 | 输入、真实结果、历史、比较、取消与恢复 | 完整声明输入到真实运行；离页不串结果，取消有真实终态 |
| U3 修改审阅 | 多文件diff、验证与测试、比较、应用/撤销、新版本 | 同一提案真实验证→授权写入→看到更新源码→核对撤销 |
| U4 项目与设置 | 页面打开目录、分析、最近项目、切换、测试设置、重启恢复 | 两项目切换与状态隔离；声明设置真实生效 |
| U5 Agent与3D | 交接上下文、收到提案证据、空间定位 | 真实Agent提案可由人审阅；3D选区进入同函数工作台 |
| U6 最终包 | 可启动的完整体验、使用说明与证据 | 仓库外从最终包完成开发者与Agent两条旅程 |

U1-U3 可先用现有启动方式开发验证；U4 必须补真实项目入口。不要因项目启动器尚未完成而停止独立页面工作，也不要交付六页空壳后转去后台研究。

普通实现、组件拆分、依赖选择自行决定。保留共享工作树与历史证据；没有新的实际问题不反复扩大检查。设计图用于布局，真实交互和数据用于完成判定。原型样例不作为产品数据。

按改动运行现有相关检查，交付前运行适用综合检查：

```sh
python3 scripts/verify.py --label <本次交付> --out evidence/development/<唯一目录> --keep-going
git diff --check
```

UI必须实际浏览器点击并核对目标/版本/输入/结果，写入核对文件字节。一份报告+progress当前指针足够。自测标明待独立复审；不因等复审停止已授权的独立下一步。

语言中立、开发者与Agent共同使用、2D/3D方向不变。保持本地源码默认不外传、静态解析不执行代码、执行和写入有授权、固定版本与实际依据、工作有界可取消。架构/旧文档不限制常规实现调整。

旧 v4.0 执行顺序已[保留存档](../evidence/documentation/atlas-ui-v2/work-order-v4-before.md)，作为历史交付上下文，不继续从 S1 重做。
