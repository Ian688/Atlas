**当前开发：探索页的项目地图与多展示区。** 入口是[最新功能设计](design/atlas-explore-next/DESIGN.md)、[可点击原型](design/atlas-explore-next/index.html)、[开发 Agent 提示词](design/atlas-explore-next/DEVELOPMENT_PROMPT.md)，顺序见[任务书 v6](DAILY_DEVELOPMENT_WORK_ORDER.md)。

探索页的新布局以项目树为默认入口，节点提供三来源简介、可编辑解析、批注与类型操作；多个独立区域承载节点标签。交付必须接真实数据和已有运行/审阅能力，不能直接发布样例原型。

其他页面保留[六页设计 v2](design/atlas-v2/README.md)和现有实现，按新探索页的衔接需要改进。[v2 标注图集](design/atlas-v2/gallery.html)仍可参考，不继续用旧探索布局覆盖新方案。
