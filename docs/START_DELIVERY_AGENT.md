3. **项目与恢复**：用户可以指定自己的项目路径并进入工作台，不需要复制固定 demo、手抄 analysis id 或改代码。允许“本地启动命令传路径 + 浏览器工作台”作为首版入口；无需为目录选择器另造桌面壳。分析有状态、错误和重试，取消确实停止分析；单次运行/验证有有界终态，不能永久转圈。重新启动能继续最近项目，恢复仍有效的选区/页签/草稿；身份无效时明确重定位或拒绝。2D/3D 往返保留对象和版本。
