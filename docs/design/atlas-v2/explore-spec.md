# 项目入口、代码探索与结构定位

本稿配套 `explore.js`，是可点击设计样例，不接真实接口，不证明分析、运行或文件变更已经发生。正式产品使用当前 vanilla JS / CSS、2D SVG 与已有 3D renderer；不为设计稿先更换前端框架。

## 页面与任务

- **项目 home**：选择本地目录或继续最近项目；用户立即知道代码是否可读、是否已经分析、下一步去哪里。
- **探索 explore**：在同一屏搜索函数、读一跳调用关系、定位源码、追踪值来源，然后带当前对象进入运行。
- **结构 city**：从目录和文件位置进入函数；与探索共享对象，保留自己的镜头。3D 是空间索引，不是运行仪表盘。

示例项目 Papertrail，问题为“高折扣让订单出现负金额”。`charge(amount, {rate})` 调用 `clampRate`，后者只限下界，故需要进一步通过真实输入核对上界。源文件 `src/pricing/money.js`。源码卡与关系图是一份样例模型；正式内容均由接口提供。

## 区域与交互交付表

|---|---|---|---|---|
| H1 打开项目 | 目录输入框、打开项目、建立索引不执行代码说明 | 空路径就地拒绝；输入本机绝对路径→打开→分析进度→完成后进入探索 | 路径错误保留输入；分析中取消；取消后可重开；语言不支持明确范围并给示例入口 | **新增本地项目打开编排**，复用 CLI index/job，不可假定已有 HTTP 目录打开接口。可由启动器先选择目录、启动对应服务，页面消费会话结果 |
| H2 最近项目 | 名称、路径、分析状态、上次函数、文件/函数/未知概览 | 点击项目继续有效选区；查找函数进入探索；结构定位进入 city | 首次无项目显示“打开你的第一个项目”，不造最近项目。项目失效给重新选择。重定位后按真实结果恢复草稿 | 当前 ui-state/relocate 可复用；跨项目最近列表及启动/切换服务编排需新增。report 供统计，不能数首屏 nodes |

| E1 搜索 | 可输入名称或路径；每行函数名+路径；选区高亮 | 输入并确认/搜索→有界匹配列表；选中→标题、图、源码同步；无结果→清空搜索 | loading/empty/error/partial 分开；分页“加载更多”保留查询；错误局部重试；键盘上下与 Enter 正式补齐 | search；已有 nodes 不承担全库检索。搜索 debounce、generation 防迟到 |

| E4 源码依据 | 文件路径、行号、当前锚点、展开阅读、交给 Agent、查看修改 | 点击行定位；扩大→模态阅读；关闭保留位置；Agent→带目标上下文；修改→同对象提案页 | 源码独立加载/错误/截断；长行横滚；定位仅滚动此面板；截图样例不作为源码事实 | source/context、selection；Agent 跳转交互由 agent 页接续，不自动上传源码或发送模型 |

## 布局与状态行为

探索主内容区三列 220px / 弹性 / 340px；项目导航由共享壳提供。结构页小于 1100px 转单列，探索小于 700px 单列，390px 保证控件可用。小于 1200px 可用宽时源码下移，不把图压成细条。区域标识 `data-region` 供标注截图，正式关闭标注。字体与按钮继承共享壳的暖白、墨色、青绿主题。

搜索随输入刷新，保留焦点和光标；真实异步接口可带约 180ms debounce。对象切换保留页面视角，源码锚点重置到新对象。页签只改变 lens，不能偷偷切函数。父级 `s.entity` 跨 explore/run/review/city 共用；真实实现使用 analysis + entity，不只函数名字。

正式页面未知数量跟随当前对象接口，原型在 charge 显示“1”只为展示设计。工程实现需把静态模板数据一并替换，不能用本稿的样例业务描述作为生产函数解释。结构图样例高度与统计只解释视觉编码；正式量化用真实可展示范围，不许声明完整覆盖。

home 打开分析为明确的等待状态，原型有“演示分析完成”控制方便评审；正式进度来自 job 状态，取消必须等服务确认，不能点按钮就造终态。已存在可用旧分析时允许继续阅读旧版本，并明确“正在更新”；首次分析无数据不显示空图冒充已完成。

## 实施与验证顺序

1. 先接共享选区、函数搜索、源码和一跳图，让 E1→E2→E4→run 成为真实可点击主路径。
2. 接来源/未知局部资源、返回历史、扩大源码与空错等待。把未知锚点作为运行前帮助，不设置额外必经向导。
3. 接 home 启动器/最近项目与分析状态。现有服务分析固定时，需要真实的服务切换，不能仅改顶栏项目名。
4. 复用已有 3D，按 D1/D2 改控件、图例和 reveal；材质不是这次验收门槛。

验收：搜索一个非首屏函数→选图节点→点调用边见正确源码→返回→切值来源→带对象进入运行；快速 A/B 切换时迟到 A 请求不覆盖 B；切项目、重启、源码插行后不默默沿用错误草稿；选择 3D 文件里的函数后 2D 标题/源码/运行目标完全一致。无数据、读取失败、分析取消、语言不支持分别检查用户能采取的下一步。

SVG 节点与调用边提供 role=button、tabindex 和说明，由共享壳统一 Enter/Space 激活。边有 18px 透明命中区域，携带 caller 与具体调用行；点击入边可以切到调用者再定位，不能一律高亮当前函数第二行。结构建筑填色随实际选区，筛选后淡化建筑同时退出键盘与指针命中。
