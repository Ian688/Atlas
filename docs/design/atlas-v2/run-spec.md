# 运行与验证页

本页回答：这组输入会得到什么结果，修改后是否发生变化？主入口来自探索页“运行函数”，审阅页“比较行为”，以及 Agent 任务的运行记录。共享 Papertrail 样本 `src/pricing/money.js::charge(amount, {rate})`：100 / 1.5 基线返回 -50，修复后返回 0；100 / 0.2 两侧均为 80。

`run.js` 是交互设计原型，计时与值计算只用于演示排版，不是 Atlas 执行证据。产品实现接现有 runner，不复制原型的 JS 计算。所有页面保留父级醒目的原型说明。

## 版面与区域

父级提供 202 px 主导航与标题栏；内容区采用左 330 px 输入，右弹性结果的两栏。小于 1000 px 时左侧收至 290 px；实际产品小屏按输入→结果→历史单列，不隐藏操作。

| 编号 | 位置 | 显示内容 | 实现落点 |
| --- | --- | --- | --- |
| R1 | 内容区顶端横条 | 函数签名、文件、固定分析版本、查看源码 | 共用 selection；前端视图切换 |
| R2 | 左栏 | 参数标签、类型、JSON 字段、预置用例、主运行按钮 | profile 驱动字段，web/app.js 输入草稿与 exec |
| R3 | 左栏渐进展开 | this、globals、运行边界、超时 | 既有 this_arg/globals 输入；不推断为授权 |
| R4 | 右上，至少 400 px | 返回值/异常/拒绝；结果、本次输入、输出日志三个页签 | 既有执行记录与比较响应，前端 renderer |
| R5 | 右下 | 当前函数运行记录、完整输入复用 | GET /api/exec-records |
| R6 | 原型内容末尾 | 一键浏览异常状态 | 仅原型，不进入产品 |

结果为 number 的示例用大字号单值；对象与数组的真实结果使用可折叠 JSON 树，类型、字段路径、复制值，以及显示截断的“加载更多”。字符串保持换行并可复制；null 与 undefined 区别显示；不得将大对象全部一次插入 DOM。按服务器编码解码，不把未知值打印为 null。原型 charge 返回标量；“结构结果”按钮另有明确标注的对象组件样例，不称其为charge的实际返回。

## 操作契约

| 按钮/动作 | 出现位置与反馈 | 状态 / 接口 | 现状 |
| --- | --- | --- | --- |
| 查看源码 | 到探索页定位同一函数与版本 | selection 共用；保留草稿 | 既有能力，换布局 |
| 折扣越界 / 正常折扣 | R2 填 100 + 1.5 / 0.2，不自动运行 | 本例预置；通用项目由参数与已有记录提供输入 | 原型专属样本；不得对任意函数硬编码 |
| 清空 | 清空参数，保留高级字段；下一次运行行内提示缺失 | 前端草稿 | UI 新整理 |
| 高级输入与运行条件 | 原位展开 this/globals 与边界，不弹全屏 | POST /api/exec 接受 this_arg/globals | 已有 |
| 运行这组输入 | 先本地校验，R4 显示等待；固定输入记录；编辑草稿不改变在途请求 | POST /api/exec {symbol,args,this_arg,globals,timeout_ms,allow_effects} | 已有同步请求；异步执行控制见下 |
| 取消运行 | 运行按钮原位变取消；R4 显示“取消中”，服务器确认后“已取消” | 新增执行 job/start/status/cancel 公共能力，复用引擎取消信号 | HTTP 取消尚缺，不得用 AbortController 冒充停止进程 |
| 结果 | 展示真实返回/抛出/拒绝/超时/取消，附版本、run id、耗时 | 实际记录 verdict/value/thrown/spec 等 | 已有；补呈现 |
| 本次输入 | R4 展示运行时固定的 args/this/globals，避免混同左侧草稿 | record.spec | 已有 |
| 输出日志 | R4 展示 stdout/stderr；空时“没有控制台输出” | 使用响应实际字段，输出截断需提示 | 核对最终返回 schema；缺字段再贯通，不能固定空日志 |
| 比较修改前后 | R4 变双列，各自显示版本与结果，同一完整输入；底部到审阅页 | POST /api/exec-compare {entity,args,proposal_id,this_arg,globals,timeout_ms,allow_effects} | 已有；多提案时新增选择器，不默认最后一份 |
| 返回单次结果 | R4 回上一次单次记录，不重新执行 | 保留 singleRecord 与 compareRecord 分开 | 前端需落实；原型简化为同一示例结果 |
| 审阅提案 | 到对应 proposal 的审阅页，保留比较记录引用 | 共用 proposal/analysis selection | 已有基础，新增路由串联 |
| 重填输入 | 将 record.spec 全量复制到草稿，toast“尚未运行” | GET /api/exec-records；不自动 POST | 已有 |
| 查看运行条件 | R4 拒绝状态弹条件说明；只提供实际可授权项 | unknown_calls 可用 allow_effects 显式本次授权 | 已有；不沿用旧文档“HTTP 无法授权”的错误 |
| 允许并重试 | 关闭说明，发新的显式执行请求；不持久默认授权 | allow_effects:["unknown_calls"] | 已有 |
| 记录重试 | R5 独立重新加载，R2/R4 不清空 | GET /api/exec-records | 已有查询，补局部恢复 |

比较 UI 必须清楚选择已经验证的提案和对应 analysis。初次无提案显示“先创建或选择已验证提案”，链接审阅页；验证未完成时显示状态与去审阅入口，不能拿基线跑两遍冒充比较。左右任意一侧拒绝/异常/超时都保留各自终态，不因另一侧成功整体写“通过”。对象差异按字段呈现，不用 JSON 文本位置认定语义差异。

## 状态与恢复

- 未选函数：引导去探索选择，不展示上一函数记录。profile 加载：字段骨架和加载文案；失败只重试画像，不清空已保存输入。
- 必填缺失 / 非法 JSON：字段旁说明，聚焦首错，不发请求。JSON 类型与画像不一致时解释；无法判断时不臆造限制。
- 正在运行：目标、版本和本次输入固定；离页持续在任务区显示状态。重复点击不重复派发。完成响应按 run id + analysis + entity 归档，不能覆盖另一函数。
- 拒绝：具名条件与可行动作。fs/network/child 权限不得伪造按钮解锁；unknown_calls 使用现有窄授权。
- 抛出异常：异常名、消息、能可靠映射到源码的位置；栈折叠。不是普通 HTTP 失败。
- 超时：显示实际 timeout_ms 与终态，保留输入，允许重试。不能在前端计时达到阈值就宣称后端已终止。
- 请求断线：显示“执行结果未知”，先重新查询记录；没有幂等/执行 id 之前不得盲目自动重试。
- 无历史：简短空状态；失败：局部重试；完整输入复用保留 this/globals 和适用版本身份。
- 数据很长：值树按深度折叠、可访问键盘操作、滚动容器和输出截断说明。主按钮不被结果挤出视口。
- 草稿：按项目+analysis+entity 保存，跨版本重定位后显式迁移完整草稿，关闭前最后一次变更需可靠保存。重启恢复是体验组成，不作为此轮重新做后端的理由。

## 技术与交付顺序

沿用原生 JS/CSS 与 Rust HTTP，组件可拆 `RunInputEditor`、`ExecutionResult`、`ExecutionComparison`、`RunHistory`；不因版面重设计重建语言引擎。先接通 R1/R2/R4/R5 的真实单次链，再接已有前后对照，最后补 HTTP 真取消与状态恢复。没有实际异步取消时按钮可显示“停止等待（执行可能仍在继续）”，但不能把临时退路交付成“已取消执行”。

代码核对：`crates/atlas-app/src/server.rs` 的 ExecRequest / ExecCompareRequest、exec 与路由清单；`web/app.js` 的 renderExecHistory / refillFromRecord。当前 exec 创建取消通道但不暴露取消路由，前端不能凭 HTTP 断线证明 runner 已停。

验收用真实指针跑：越界返回 -50→完整输入页→重填正常用例返回 80→选择提案 P-104→比较 -50/0→进入同一提案；再测缺输入、JSON 错误、unknown_calls 拒绝及显式重试、真实超时/取消、离页完成、记录失败重试。截图验证信息层级，实际执行记录证明行为。原型不替代产品验收。
