# 给实现 Agent：把 Atlas 完整界面做出来

你的任务是把 Atlas v2 设计接成真实可用的产品。用户最新决定：当前主线是 UI 与完整操作体验，后端按界面需要补齐；之前 R1–R4 复审问题融入相应用户流程，不要继续把它们单独作为整轮主任务。

## 先看什么

1. 打开同目录 index.html，按顶栏“操作路线”实际点击一遍；看 gallery.html 的全页和标注图。
2. 读 DESIGN.md 的页面连接、区域与技术表，再读你当前实现页面的 explore-spec.md / run-spec.md / review-spec.md。
3. 读仓库 README、ARCHITECTURE、HANDOFF 后，按 DAILY_DEVELOPMENT_WORK_ORDER v5 的 U1→U6 推进。代码和历史报告用来识别可复用能力，不另起后台项目。

## 最终交付给用户什么

一个本地可启动的 Atlas：能从界面打开项目、找到函数、看关系和源码、填写输入并读取真实结果、看到 Agent 返回的提案、验证并审阅、确认应用、查看更新代码、必要时撤销。项目定位还可通过 3D 进入同一函数。无需用户填写 analysis id/entity id 或先理解内部数据库。

首要基准是用户点击后的结果。每交一个页面都必须带真实数据接线和状态恢复，不能六页只画外壳，也不能后端做完却找不到入口。

## 顺序与每步完成线

### U1 共用空间与探索（G / E）

重排现有布局，接入六页导航、项目/版本上下文、搜索、对象选区、源码、关系/值/未知。先让“查找→点关系→读源码→进入运行”可用。保留现有接口/引擎，不重写已可用分析。

完成：真实项目非首屏函数能找到；节点/边对应正确源码；快速切换不串数据；1024可操作。其他尚未接线页面显示明确进度或真实空态，不展示原型假结果。

### U2 运行验证（R）

画像驱动输入，高级this/globals，返回/异常/拒绝/超时、输入快照、日志、历史复用、同输入对照。需要真实运行取消时补引擎控制到HTTP；后台任务状态可离页后找回。

完成：四种不同签名函数保持正确目标；编辑草稿不改旧记录；两侧保留各自版本和完整声明；拒绝有实际可用恢复；取消以服务终态为准。

### U3 修改审阅（C）

提案列表、多文件diff、静态影响、验证过程和测试输出、输入对照、具体目录确认、应用/撤销、进入新版本。测试未跑与失败必须分开。旧“显式版本请求被忽略”在这里修掉。

完成：一个真实提案经验证、实际写入、打开更新源码、撤销核对；另一个提案并行查看不串结果。当前文件漂移时保护用户编辑并给下一步入口。

### U4 项目入口与设置（H / G）

接通页面打开目录、分析任务、最近项目、真实切换、重新分析、声明测试设置和断线恢复。复用启动器/index/job/serve，不要求新增通用项目平台。已有单分析服务限制要通过真实编排解决，不能只改标题。

完成：用户按交付说明启动后，在页面打开两个不同项目；来源/版本/草稿互不串用；分析可取消；服务重启、源码移动后恢复正确对象和适用输入。测试设置实际生效并能在验证输出核对。

### U5 Agent 协作与3D（A / D）

Agent页复制明确目标+有界上下文获取方法，展示真实提案与关联证据，跳转同一提案。它不内置模型、不假派单。3D复用现有WebGL2，补目录/文件/成员、过滤、镜头和2D联动；不把原型SVG模型移过去当成正式3D。

完成：另一个真实Agent通过Atlas提交修改，用户从Agent页进入对应提案并核对；3D文件→函数→运行的对象相同。Agent身份按真实会话/声明展示，不能声称已认证某模型。

### U6 最终包体验交付

从复制后的最终包走整个流程，检查1440/1600与1024布局、键盘、长路径/源码/diff、错误恢复、离页任务。390保证基础操作可读可达，不让移动端精修拖住桌面交付。最后跑适用综合检查，交一份报告、真实操作截图、包和最短命令。

## 实现自由与必要一致性

- 当前技术栈原生JS/CSS、SVG+elkjs、WebGL2、Rust/Axum、现有worker。可以拆模块、用成熟组件，普通选择不必申请许可；不为重设计先迁移框架。
- 图片是布局基线，规格是点击行为。改尺寸、布局或库可以，但须实际操作确认任务更容易完成。遇规格遗漏按同一页面规则补齐，记录一句即可。
- 原型计时器、固定数量、样本公式和假版本只是评审材料，不能复制为产品结果。真实接口缺字段就补最短完整链；响应晚到不能覆盖新的对象或提案。
- 不将裸id、令牌、JSON内部统计堆在首屏。普通参数按画像编辑；高级JSON/证据id放合适详情，仍可供Agent获取。
- 源码与版本对应、静态/观测/提案可区分、本地数据不默认外传、执行与写入按授权、工作可终止。这些让用户能信任操作，不能靠界面文案替代实现。
- 浏览器UI处理目录要通过本地服务/启动器，不能把浏览器File API里的虚拟路径当成真实项目根目录。设置中的测试命令必须是操作者配置，外部提案不能自行决定要执行的命令。
- 不清理共享工作树，不覆盖历史证据，不无限美化。本轮不扩展新语言/新平台，除非实际阻塞当前界面旅程。

## 怎样证明完成

开发中用相关检查。交付前用真实浏览器点击上述路径，并核对接口的版本/目标/输入、真实返回值与实际文件字节；不能仅有DOM单元测试或截图。原型check.cjs只检查设计，不是产品验收脚本。

一份新报告写清：页面新增什么、仍未接线什么、真实旅程通过/失败、检查退出码、最终包路径。更新progress与handoff当前指针，自测与独立复审分开。完成U1后自动推进，不每页等待重新批准。
