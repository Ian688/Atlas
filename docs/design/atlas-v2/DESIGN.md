# Atlas 完整界面与交互设计

版本 2.0。用户最新决定：先把完整用户界面设计清楚，再按前端任务需要实现后端。本文与三份分页面规格共同定义本轮设计；图片展示布局，规格定义按钮和动态行为。工程可调整组件与尺寸，保持操作结果和信息层级。

## 一条工作流程，六个页面

```text
项目 → 探索代码 ⇄ 运行验证
          ↑          ↓
       3D 地图    修改审阅 ⇄ Agent 协作
                      ↓
                  应用 → 新版本 → 继续探索
                      ↘ 撤销 / 文件冲突处理
```

项目入口是开门；探索、运行、审阅是主要工作；3D 是结构定位；Agent 是外部协作的交接与结果入口。六页共用项目、版本、选区、提案和任务状态。不是六个互不相干的工具。

产品面向开发者与 Codex 等编程 Agent，不预设目标项目语言。JS/TS 是当前真实支持范围，在导入能力提示中说明；不写进产品名称或全局功能定义。多语言差异由能力/画像驱动，页面不用扩成每语言一套。

### 页面连接必须传什么

| 从哪里到哪里 | 带过去什么 | 抵达后呈现 |
|---|---|---|
| 项目→探索 | projectId、analysisId、最近有效 selection | 已选对象或可搜索的项目入口；没有旧选择就不给假默认函数 |
| 探索→运行 | 同一 analysisId/entityId、完整草稿 | 正确签名和字段；不得换成示例 charge |
| 探索→Agent | 当前上下文引用、范围、版本、函数 | 可编辑交接目标，尚未发送 |
| Agent→审阅 | proposalId、其基线、验证引用 | 同一提案被选中，显示相同 diff/结果 |
| 审阅→对照 | 指定提案、两侧版本、同份声明输入 | 每侧独立返回/异常/拒绝，不合并成“通过” |
| 应用→探索 | 真正发布或重新建立的新 analysis、重定位结果 | 更新源码；不能只改版本标签 |
| 3D→探索 | 所选文件中的真实 entity、analysis | 标题、源码和随后运行的目标都相同 |

浏览器前进/后退恢复页面与选区，任务页签保存各自滚动与编辑。路由结构可沿用现有 fragment；不要为了路由改造迁移全部前端框架。版本不匹配的接口必须明确拒绝，选区重定位后草稿才可有依据地迁移。

## 共享空间与视觉规范

默认桌面参考 1600×1050，1440 宽也应有完整主要操作。全局导航 202px；顶栏 62px；内容左右 30px；页面主标题 27px。任务主要区域保持 13px 正文、12px 代码、足够行距。灰色小字只承担次要信息，不承载唯一错误原因。

| 区域 | 内容 | 点击与动态行为 | 技术落点 |
|---|---|---|---|
| G1 左导航 | 项目选择器、搜索、六个页面、后台任务、设置 | 切任务保留对象；当前项高亮；任务计数来自在途工作；项目切换必须切真实服务/状态 | HTML nav + JS state/router；ui-state；项目编排新增 |
| G2 顶栏 | 当前页、当前代码版本、帮助 | 版本弹层列基线/候选与重新分析；帮助显示快捷键 | report/patch、真实版本选择编排 |
| G3 底状态 | 本机状态、当前对象/版本、证据类别说明 | 详细信息按需打开；不滚动堆所有内部指标 | 轻量状态投影 |
| 对话框 | 复制交接、连接、设置、diff、输出、确认写入 | Esc/关闭返回焦点；长内容内部滚动；输入错误原位保留 | 原生 dialog，焦点管理；草稿独立保存 |
| Toast | 已复制、草稿已填、任务完成 | 短暂出现但不作为失败的唯一记录；完成可链接结果 | aria-live status，真实任务事件 |

色彩：暖灰底 #f7f8f6、白内容、墨绿文字 #203330、主动作青绿 #137b67、分隔线 #e1e7e3。警告暖黄、失败赤褐，不把所有分析未知涂成严重故障。圆角内容区12px、按钮7px。以分栏、文字和留白组织内容，避免每个字段单独一张卡片。只给当前任务一个主要执行动作，其余为次级按钮或文本入口。

调用图用细线、有明确方向的节点；选中与 hover 可区分。源码中青色高亮只标阅读定位。返回值成功不自动染亮调用路径。运行中只在任务状态用轻量进度，不让背景流动制造“真实执行”的错觉。

## 静态与动态区域总表

编号可通过原型“标注区域”查看。更详细的按钮契约见分页面规格。

| 页面 | 常驻骨架 | 会改变的区域 | 关键弹层/异常 |
|---|---|---|---|
| 项目 H1–H3 | 打开路径、最近项目、示例入口 | 分析进度/范围、最近任务 | 空路径、目录失败、不支持、取消、已有旧版本可读 |
| 探索 E1–E4 | 对象标题、搜索列、阅读中心、源码 | 搜索结果、关系/值/未知、源码锚点、返回历史 | 无匹配、局部加载失败、截断、展开源码、上下文预览 |
| 3D D1–D2 | 空间模型、目录过滤、文件检查器 | 相机/缩放、选中文件、函数成员 | 无成员、图形能力失败→列表/2D、范围省略 |
| 运行 R1–R5 | 目标、输入、结果、历史 | 字段、运行状态、结果/输入/日志、双侧对照 | 非法JSON、缺输入、拒绝授权、异常、超时、取消、断线、无记录 |
| 审阅 C1–C5 | 提案列、文件diff、证据列、底部行动 | 当前提案/文件、验证步骤、测试输出、比较、写入状态 | 无提案、验证失败、未跑测试、确认目录、漂移拒绝、新版本 |
| Agent A1–A5 | 上下文交接、收到的提案、记录 | 草稿、上下文范围、提案/验证/运行引用 | 复制失败、导出失败、没有收到结果、连接说明 |

原型里的 H3/R6/页底状态切换器属于设计工具，不能作为正式产品功能。少数灰字“样例”帮助评审识别原型；正式界面用实际范围和结果替换，不照搬免责声明。

## 全局按钮与弹层契约

| 操作 | 出现什么 | 成功/失败后怎么走 |
|---|---|---|
| 项目选择 | 当前与最近项目，打开新目录入口 | 切换完成更新服务/项目；失败保留旧项目可读 |
| 搜索 / ⌘或Ctrl K | 名称、路径和常用操作的命令面板 | 输入筛选，Enter进入，Esc关闭；不需要用户知道对象 id |
| 顶栏版本 | 基线/候选、当前选中、重新分析 | 候选去提案；切分析走真实数据上下文；错误可返回原版本 |
| 后台任务 | 在途任务、阶段、耗时、取消；最近完成可跳结果 | 取消中等待确认；失败留记录；不能写死“0 个任务” |
| 项目设置 | 路径、声明测试argv、超时、运行/写入条件 | 输入校验；操作者授权的设置应用到服务；不能只是本地表单保存 |
| 本机连接 | 服务状态与重新连接 | 重连保留草稿；在途执行结果未知时查记录，不盲重试 |
| 帮助 | 搜索、导航、关闭弹层快捷键与主流程 | 不强制首次引导，不挡正常工作 |
| 证据说明 | 静态关系、运行结果、修改提案三类区别 | 关闭回原位置；详细字段留在对应详情 |

## 动态行为与恢复

- 每个数据区域独立维护 loading / ready / empty / failed / partial。局部失败只重试本区域，输入与其他区域继续可用。无数据与没取到数据不能用同一句话。
- 编辑输入只更新草稿，不全页重渲染夺取焦点。表单按钮在请求中防重复；运行中可编辑下一次草稿，但记录保留发送时完整输入。
- 实际运行与验证在离页后继续，状态按任务 id 归档。响应到达不抢选区；后台任务提供返回结果入口。取消要等服务确认进程停止，不能用断开 HTTP 冒充。
- 验证不自动应用。应用确认只出现真实授权目录、文件集合、版本和验证状态。测试未运行须明确确认，不造通过；文件漂移保留当前编辑并提供查看差异。
- 持久状态按项目/版本/实体组织；快速关闭和源码移动后的恢复纳入对应页面实现。旧 R1–R4 在这些操作里处理，不再独立主导一轮后端工作。
- 复制失败保留可选文本；导出失败保留范围和重试按钮。Agent 页面“复制交接”不等于发送，“收到提案”以 Atlas 记录为准，不推测外部 Agent 的过程。

## 响应式、键盘与长内容

桌面三栏主要用于探索与审阅。可用内容不足时，先将源码/证据移到中区下方，保留可用宽度；不把代码压到一字一列。1024 宽应可完成全部主任务；390 宽用单列和横向任务导航保证基础操作。3D 小屏保留列表进入2D，不要求塞入完整城市。

代码和diff容器允许长行内部横滚，页面本身不横溢；长路径可折行或省略并完整展示于详情。每个滚动区有明确标题；主要运行/应用按钮容易找到，不随大结果埋到几屏后。正式版图/源码区可拖动分隔条调整宽度，双击恢复默认；分隔条支持键盘调整，不要求在原型实现真实编辑器级布局系统。

焦点轮廓可见；非原生SVG节点实现Enter/Space；图边扩大命中区域；颜色配文字/图标一起表达状态。弹层关掉回到触发位置，保留未提交草稿。尊重 reduced-motion；图形不可用时展示成员列表和定位入口。

## 技术栈与区域对应

| 层 | 本轮采用什么 | 用在哪里 | 改动入口 |
|---|---|---|---|
| 页面 | 现有浏览器 HTML/CSS/JavaScript，按模块拆组件 | G/H/E/R/C/A全部界面、路由与草稿 | web/index.html、style.css、app.js；可以新增模块并同步Rust静态资源注册 |
| 2D 图 | 现有 elkjs 布局 + SVG/DOM | E2 节点、边、聚合、可点击依据 | web/layout.js、hierarchy.js |
| 源码/diff/值 | 可复用源码组件与统一diff解析；语法着色按需选成熟本地库 | E4/C3/R4 | 前端renderer；区分UTF-8字节与显示行号，依赖随包分发 |
| 3D | 现有 WebGL2 renderer，复用层级与 selection | D1/D2 | web/city3d.js；原型SVG不替代正式3D |
| 本机服务 | Rust + Axum，消费现有公开接口 | 查询、运行、提案、验证、应用撤销 | crates/atlas-app/src/server.rs/main.rs |
| 核心 | 已有 Rust分析/执行/补丁/存储 | 为上述交互提供真实结果与版本 | atlas-engine、runner.rs、patchwork.rs |
| 语言 | 当前 TypeScript worker；之后按需求接新语言 | 索引与运行画像供统一页面消费 | workers/typescript，不绑定全局UI文案 |
| 检查 | 真实 Chrome/Playwright + 相关Rust/HTTP检查 | 指针、键盘、恢复、输入/结果一致性 | 浏览器旅程与已有scripts |

不要求引入 React 或换 Rust 核心。已有库不合适时可以替换，但不要把框架迁移作为画好页面的前置。原型的window状态与计时器只是演示，正式实现沿用/整理真实状态管理与接口。

### 确认已有的接口

search/node/nodes/edges/reach/source/flow/profile/context、exec/exec-records、patches/patch/propose/verify/apply/revert、exec-compare、ui-state、relocate、contract。以实际server契约核对字段，不从图片杜撰响应。

### 为界面补齐的最小能力

| 用户按钮 | 当前缺口 | 最短实现要求 |
|---|---|---|
| 打开/切换项目、最近项目 | 固定analysis的serve不是项目管理器 | 本机启动器或受信服务负责目录/index/会话切换，页面显示作业；浏览器不能假装拿到了绝对目录 |
| 取消运行/后台任务 | 当前HTTP没有真实执行取消入口 | 复用引擎控制，给执行id、status/cancel，确认终态；不另建通用调度平台 |
| 应用后打开新版本 | HTTP固定一份analysis，显式版本目前可被忽略 | 真实切换/启动对应版本服务，或扩展受控版本路由；错误版本明确拒绝 |
| 项目设置 | 测试配置已有CLI启动声明，页面保存未接 | 由可信本机操作者更新配置/重启编排，页面完整呈现生效结果 |
| Agent按交接查看成果 | 已有提案/记录，未必有完整handoff关联 | 先按真实proposal归组；可选handoff引用补足，不能发明已认证身份和完整外部日志 |

上述均有具体前端落点。与本轮页面无关的后台增强继续放后续。
