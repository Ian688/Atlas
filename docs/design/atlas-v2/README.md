## 使用说明

1. 原型首页点击“探索示例项目”，选 charge；探索页能搜索、选图节点、定位值来源。
2. 进入运行，用 100 和 1.5 看返回 -50，再比较候选修改后的 0；其他函数有各自参数。
3. 去 Agent 协作编辑交接目标，预览文本，再打开它返回的 P-104。
4. 审阅中切文件、查看测试输出、编辑对照输入、确认应用；打开新版本可看到新增金额下限，再返回撤销。
5. 页底的“原型状态”只用于评审各种失败/空状态，正式产品删除。

设计图由原型在 Chrome 中直接渲染，中文、编号、按钮位置和源文件一一对应；不是独立绘制的概念图。3D 页是可操作的等距结构原型，正式版本使用已有 WebGL 渲染器。正式相机旋转、性能和运行链不由这些图片证明。

原型文件：index.html + style.css + shell.js + explore.js + run.js + review.js。同目录一起交付。示例都在本地，不依赖外部字体、图片或 CDN。设计修改后运行 check.cjs 重新生成图片，保持图文一致。
