# 开发状态

[progress.json](progress.json) 保存历史窗口和当前断点，不替代代码、验证或产品任务书。当前队列统一见 [执行任务书](../DAILY_DEVELOPMENT_WORK_ORDER.md)。

执行者只需更新当前动作、对应窗口/报告、涉及能力的实际状态。历史窗口和复审保留；无需为每次小改动填写全部 W 或复制证据。独立复审状态只由实际复审更新。

阶段报告用 [简短模板](DAILY_REPORT_TEMPLATE.md)。记录自己变更对应的源码身份、检查退出码和用户路径；新证据写入新目录，不覆盖原结果。没有运行的检查明确未验证，文档更新不提升产品状态。本地源码、秘密、令牌和数据库不进入公开材料。
