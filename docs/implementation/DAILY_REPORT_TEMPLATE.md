# Atlas 阶段交付

模板：只填写与本次有关的内容；不适用的小节可删。一个报告供接续和复审使用，无需复制成多份台账。

## 用户结果

- 任务：T1 / T2 / T3 或用户明确指定的任务。
- 现在能完成：入口、操作和结果。
- 剩余：未完成或未验证的步骤；是否阻塞本任务。

## 改动与身份

- cwd、实际 HEAD；提交或 diff/新增文件位置，包含自己的未提交变更。
- 关键改动及原因。涉及协议/身份/迁移时说明兼容处理；否则省略。

## 实际验证

| 命令或浏览器操作 | 最终退出码/操作结果 | 日志或截图 | 验证范围 |
|---|---|---|---|
| 填写实际执行 | 未运行不填 0/PASS | 本地证据路径 | 明确 |

保留关键失败及修复结果；重型性能或环境资格仅在本任务涉及时报告。自测通过写 NEEDS_INDEPENDENT_REVIEW，不自行写独立验收通过。

## 接下来直接做

一个具体文件/入口、失败复现或缺失步骤、期望结果。若阻塞，写解锁条件和仍可推进的独立步骤。简要标出复审最需关注的风险，无需凑固定条数。
